# Plan: E13 — Langfuse and LangSmith importers

**Source**: [03-epics.md](../03-epics.md) E13; FR-L1, FR-L2
**Complexity**: Medium (4 stories, about a day and a half)
**Status**: planned 2026-09-26

## Summary

One row reader for the export shapes both platforms produce (JSONL, JSON array or
envelope, Parquet, gzip), then two thin mappers: Langfuse `tool` observations and LangSmith
`tool` runs. Parquet needs `pyarrow`, shipped as the `permdiff[parquet]` extra.

## Verified 2026-09-26

See the E13 entry in `03-epics.md` for the field lists and their sources. Also: `pyarrow`
is already present in the dev environment; `pyarrow.parquet.read_table(path).to_pylist()`
yields dicts with nested structs as dicts and lists as lists, so JSON and Parquet rows share
one mapping. Existing helpers to reuse: `input_map._walk` (dotted lookup), the Claude Code
importers' principal handling, `read_lines`'s skip/abort loop.

## Interfaces

```python
# importers/rows.py
Row = Mapping[str, Any]
def iter_rows(path: Path) -> Iterator[tuple[Row | RecordRejected, str]]
#   .parquet (or PAR1 magic) -> pyarrow; else text (gzip if magic 1f8b): whole-document JSON
#   (list, or {"data": [...]}) -> "path[i]"; else JSONL -> "path:lineno"
def parquet_rows(path: Path) -> list[Row]         # TraceImportError with install hint when pyarrow is absent
def parse_json_field(value: Any) -> Any            # JSON string -> object; else unchanged

# importers/langfuse.py
class LangfuseImporter: name = "langfuse"; __init__(principal_from=None); detect; read
# importers/langsmith.py
class LangsmithImporter: name = "langsmith"; __init__(principal_from=None); detect; read
```

3. **S3 langsmith** — fixtures: SDK-style JSONL (tool, llm, chain runs; naive
   timestamps), a Parquet file generated from the JSONL by `tests/fixtures/langsmith/make_parquet.py`;
   tests per AC-13.5/13.6.

## Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| Export column sets drift (Langfuse field groups, LangSmith v2_beta) | Medium | accept both key styles, ignore unknown keys, fixtures dated; docs name the groups needed (`core`, `basic`, `io`) |
| Parquet exports store JSON columns as strings | High | `parse_json_field` on `input`/`output`/`inputs`/`metadata` |
| No principal in LangSmith runs | High | `--principal-from` dotted path; `unknown` with a note |
| Fixtures are hand-built, not real exports | High | README says so; shapes follow the documented field lists; regenerate when a real export is available |
